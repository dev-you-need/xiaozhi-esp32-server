# Сборка прошивки esp32

## Шаг 1. Подготовьте ваш OTA-адрес

Если вы используете версию 0.3.12 этого проекта, то при любом развёртывании — простого Server или полном — у вас будет OTA-адрес.

Поскольку способ задания OTA-адреса при простом развёртывании Server и при полном развёртывании отличается, выберите подходящий вариант ниже:

### Если вы используете простое развёртывание Server
Сейчас откройте ваш OTA-адрес в браузере, например, мой OTA-адрес
```
http://192.168.1.25:8003/xiaozhi/ota/
```
Если отображается «OTA接口运行正常，向设备发送的websocket地址是：ws://xxx:8000/xiaozhi/v1/

Вы можете запустить модуль `digital-human`, открыть `index.html` и проверить, удаётся ли подключиться к websocket-адресу, выведенному на странице OTA.

Если доступа нет, откройте файл конфигурации `.config.yaml` и измените адрес `server.websocket`, затем перезапустите сервис и повторите проверку, пока `index.html` не начнёт открываться нормально.

После успеха переходите к шагу 2

### Если вы используете полное развёртывание модулей
Сейчас откройте ваш OTA-адрес в браузере, например, мой OTA-адрес
```
http://192.168.1.25:8002/xiaozhi/ota/
```

Если отображается «OTA接口运行正常，websocket集群数量：X» — переходите к шагу 2.

Если отображается «OTA接口运行不正常», скорее всего вы ещё не настроили адрес `Websocket` в `智控台`. Тогда:

- 1. Войдите в панель управления под учётной записью суперадминистратора

- 2. В верхнем меню нажмите `参数管理`

- 3. Найдите в списке пункт `server.websocket` и введите ваш адрес `Websocket`. Например, у меня это

```
ws://192.168.1.25:8000/xiaozhi/v1/
```

После настройки снова обновите в браузере адрес вашего OTA-интерфейса и проверьте, стал ли он работать. Если всё ещё не работает, ещё раз убедитесь, что Websocket запущен и что адрес Websocket настроен.

## Шаг 2. Настройка окружения
Сначала настройте окружение проекта по этому руководству [《Windows搭建 ESP IDF 5.3.2开发环境以及编译小智》](https://icnynnzcwou8.feishu.cn/wiki/JEYDwTTALi5s2zkGlFGcDiRknXf)

## Шаг 3. Откройте файл конфигурации
После настройки среды сборки скачайте исходный код проекта xiaozhi-esp32 от Сяге (虾哥),

Скачайте [исходный код проекта xiaozhi-esp32](https://github.com/78/xiaozhi-esp32) отсюда.

После скачивания откройте файл `xiaozhi-esp32/main/Kconfig.projbuild`.

## Шаг 4. Измените OTA-адрес

Найдите содержимое `default` у `OTA_URL` и замените `https://api.tenclass.net/xiaozhi/ota/`
   на свой адрес, например, мой адрес интерфейса — `http://192.168.1.25:8002/xiaozhi/ota/`, значит содержимое нужно заменить на него.

До изменения:
```
config OTA_URL
    string "Default OTA URL"
    default "https://api.tenclass.net/xiaozhi/ota/"
    help
        The application will access this URL to check for new firmwares and server address.
```
После изменения:
```
config OTA_URL
    string "Default OTA URL"
    default "http://192.168.1.25:8002/xiaozhi/ota/"
    help
        The application will access this URL to check for new firmwares and server address.
```

## Шаг 4. Задайте параметры сборки

Задайте параметры сборки

```
# в терминале перейдите в корневой каталог xiaozhi-esp32
cd xiaozhi-esp32
# например, у меня плата esp32s3, поэтому цель сборки — esp32s3; если у вас другая плата, замените на соответствующую модель
idf.py set-target esp32s3
# откройте меню конфигурации
idf.py menuconfig
```

После входа в меню конфигурации перейдите в `Xiaozhi Assistant` и укажите в `BOARD_TYPE` конкретную модель вашей платы
Сохраните и выйдите, вернувшись в командную строку терминала.

## Шаг 5. Соберите прошивку

```
idf.py build
```

## Шаг 6. Упакуйте bin-прошивку

```
cd scripts
python release.py
```

После выполнения команды упаковки в каталоге `build` в корне проекта будет создан файл прошивки `merged-binary.bin`.
Этот `merged-binary.bin` — файл прошивки, который нужно записать на устройство.

Примечание: если после выполнения второй команды возникла ошибка, связанная с «zip», проигнорируйте её; главное, чтобы в каталоге `build` был создан файл прошивки `merged-binary.bin`
— на вас это не повлияет, продолжайте.

## Шаг 7. Запишите прошивку
   Подключите устройство esp32 к компьютеру, откройте в браузере chrome следующий адрес

```
https://espressif.github.io/esp-launchpad/
```

Откройте это руководство: [Инструмент прошивки / веб-прошивка через браузер (без среды IDF)](https://ccnphfhqs21z.feishu.cn/wiki/Zpz4wXBtdimBrLk25WdcXzxcnNS).
Перейдите к разделу: `方式二：ESP-Launchpad 浏览器WEB端烧录`, начните с пункта `3. 烧录固件/下载到开发板` и действуйте по руководству.

После успешной прошивки и подключения к сети разбудите xiaozhi словом активации и следите за сообщениями в консоли на стороне server.
