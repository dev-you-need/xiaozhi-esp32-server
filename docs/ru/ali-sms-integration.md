# Руководство по интеграции SMS-сервиса Alibaba Cloud

Войдите в консоль Alibaba Cloud и перейдите на страницу «Сервис коротких сообщений»: https://dysms.console.aliyun.com/overview

## Шаг 1. Добавление подписи
![Шаг](../images/alisms/sms-01.png)
![Шаг](../images/alisms/sms-02.png)

В результате описанных шагов вы получите подпись — запишите её в параметр панели управления `aliyun.sms.sign_name`.

## Шаг 2. Добавление шаблона
![Шаг](../images/alisms/sms-11.png)

В результате описанных шагов вы получите код шаблона — запишите его в параметр панели управления `aliyun.sms.sms_code_template_code`.

Обратите внимание: подписи требуется 7 рабочих дней, отправка заработает только после того, как она будет успешно зарегистрирована у оператора.

## Шаг 3. Создание SMS-аккаунта и предоставление прав

Войдите в консоль Alibaba Cloud и перейдите на страницу «Управление доступом»: https://ram.console.aliyun.com/overview?activeTab=overview

![Шаг](../images/alisms/sms-21.png)
![Шаг](../images/alisms/sms-22.png)
![Шаг](../images/alisms/sms-23.png)
![Шаг](../images/alisms/sms-24.png)
![Шаг](../images/alisms/sms-25.png)

В результате описанных шагов вы получите access_key_id и access_key_secret — запишите их в параметры панели управления `aliyun.sms.access_key_id` и `aliyun.sms.access_key_secret`.

## Шаг 4. Включение функции регистрации по телефону

1. Обычно после заполнения всей вышеуказанной информации появится следующий результат; если нет — возможно, какой-то шаг был пропущен.

![Шаг](../images/alisms/sms-31.png)

2. Включите возможность регистрации для пользователей, не являющихся администраторами: установите параметр `server.allow_user_register` в значение `true`.

3. Включите функцию регистрации по телефону: установите параметр `server.enable_mobile_register` в значение `true`.
![Шаг](../images/alisms/sms-32.png)
