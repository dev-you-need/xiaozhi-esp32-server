# Руководство по использованию плагина погоды

## Обзор

Плагин погоды `get_weather` — одна из ключевых функций голосового ассистента Xiaozhi ESP32; он поддерживает голосовой запрос погоды для любых регионов страны. Плагин основан на API QWeather (和风天气) и предоставляет текущую погоду и прогноз на 7 дней.

## Руководство по получению API Key

### 1. Регистрация аккаунта QWeather

1. Перейдите в [консоль QWeather](https://console.qweather.com/)
2. Зарегистрируйте аккаунт и пройдите верификацию по электронной почте
3. Войдите в консоль

### 2. Создание приложения и получение API Key

1. После входа в консоль нажмите справа ["Управление проектами"](https://console.qweather.com/project?lang=zh) → "Создать проект"
2. Заполните информацию о проекте:
   - **Название проекта**: например, «Голосовой помощник Xiaozhi»
3. Нажмите «Сохранить»
4. После создания проекта нажмите в нём "Создать учётные данные"
5. Заполните информацию об учётных данных:
    - **Название учётных данных**: например, «Голосовой помощник Xiaozhi»
    - **Способ аутентификации**: выберите "API Key"
6. Нажмите «Сохранить»
7. Скопируйте `API Key` из учётных данных — это первая ключевая настройка

### 3. Получение API Host

1. В консоли нажмите ["Настройки"](https://console.qweather.com/setting?lang=zh) → "API Host"
2. Посмотрите назначенный вам персональный адрес `API Host` — это вторая ключевая настройка

Описанные выше действия дают два важных параметра: `API Key` и `API Host`.

## Способы настройки (выберите один)

### Способ 1. Если вы развернули полную конфигурацию с панелью управления (рекомендуется)

1. Войдите в панель управления
2. Перейдите на страницу «Настройка роли»
3. Выберите агента, которого хотите настроить
4. Нажмите кнопку «Редактировать функции»
5. В области настройки параметров справа найдите плагин «Запрос погоды»
6. Отметьте «Запрос погоды»
7. Вставьте скопированную первую ключевую настройку `API Key` в поле `API-ключ плагина погоды`
8. Вставьте скопированную вторую ключевую настройку `API Host` в поле `API Host разработчика`
9. Сохраните настройку, затем сохраните настройку агента

### Способ 2. Если развёрнут только отдельный модуль xiaozhi-server

Настройте в `data/.config.yaml`:

1. Вставьте скопированную первую ключевую настройку `API Key` в поле `api_key`
2. Вставьте скопированную вторую ключевую настройку `API Host` в поле `api_host`
3. Укажите ваш город в поле `default_location`, например `Гуанчжоу`

```yaml
plugins:
  get_weather:
    api_key: "你的和风天气API密钥"
    api_host: "你的和风天气API主机地址"
    default_location: "你的默认查询城市"
```
