# Руководство по использованию MCP-точки подключения

В этом руководстве на примере калькулятора MCP с открытым исходным кодом от Xia Ge (虾哥) показано, как подключить собственный MCP-сервис к своей точке подключения.

Предпосылкой этого руководства является то, что в вашем `xiaozhi-server` уже включена функция MCP-точки подключения. Если вы ещё не включили её, сначала включите её по [этому руководству](./mcp-endpoint-enable.md).

# Как подключить к агенту простую MCP-функцию, например калькулятор

### Если у вас развёртывание полного модуля
Если у вас развёртывание полного модуля, вы можете зайти в панель управления, управление агентами, нажать `配置角色` («Настройка роли»), справа от `意图识别` («Распознавание намерений») находится кнопка `编辑功能` («Редактировать функции»).

Нажмите эту кнопку. В открывшейся странице, в нижней части, будет раздел `MCP接入点` («MCP-точка подключения») — обычно там отображается `адрес MCP-точки подключения` этого агента. Далее мы расширим функциональность этого агента, добавив калькулятор на основе технологии MCP.

Этот `адрес MCP-точки подключения` очень важен — он вам скоро понадобится.

### Если у вас развёртывание одиночного модуля
Если у вас развёртывание одиночного модуля и вы уже настроили адрес MCP-точки подключения в конфигурационном файле, то при запуске одиночного модуля обычно выводятся следующие логи:
```
250705[__main__]-INFO-初始化组件: vad成功 SileroVAD
250705[__main__]-INFO-初始化组件: asr成功 FunASRServer
250705[__main__]-INFO-OTA接口是          http://192.168.1.25:8002/xiaozhi/ota/
250705[__main__]-INFO-视觉分析接口是     http://192.168.1.25:8002/mcp/vision/explain
250705[__main__]-INFO-mcp接入点是        ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=abc
250705[__main__]-INFO-Websocket地址是    ws://192.168.1.25:8000/xiaozhi/v1/
250705[__main__]-INFO-=======上面的地址是websocket协议地址，请勿用浏览器访问=======
250705[__main__]-INFO-如想测试websocket请启动digital-human模块，打开浏览器交互测试
250705[__main__]-INFO-=============================================================
```

Как показано выше, значение `ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=abc` в строке `mcp接入点是` — это и есть ваш `адрес MCP-точки подключения`.

Этот `адрес MCP-точки подключения` очень важен — он вам скоро понадобится.

## Шаг 1. Скачайте код проекта MCP-калькулятора Xia Ge

Откройте в браузере [проект калькулятора](https://github.com/78/mcp-calculator), написанный Xia Ge (虾哥),

После открытия найдите на странице зелёную кнопку с надписью `Code`, нажмите на неё, и вы увидите кнопку `Download ZIP`.

Нажмите её, чтобы скачать архив с исходным кодом проекта. После скачивания на ваш компьютер распакуйте его; в этот момент он может называться `mcp-calculator-main`.
Вам нужно переименовать его в `mcp-calculator`. Далее через командную строку перейдите в директорию проекта и установите зависимости.


```bash
# Переход в директорию проекта
cd mcp-calculator

conda remove -n mcp-calculator --all -y
conda create -n mcp-calculator python=3.10 -y
conda activate mcp-calculator

pip install -r requirements.txt
```

## Шаг 2. Запуск

Перед запуском скопируйте из вашего агента в панели управления адрес MCP-точки подключения.

Например, адрес MCP моего агента:
```
ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=abc
```

Введите команду

```bash
export MCP_ENDPOINT=ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=abc
```

После ввода запустите программу

```bash
python mcp_pipe.py calculator.py
```

### Если у вас развёртывание через панель управления
Если у вас развёртывание через панель управления, после запуска снова зайдите в панель управления, нажмите «Обновить статус MCP-подключения», и вы увидите список расширенных функций.

### Если у вас развёртывание одиночного модуля
Если у вас развёртывание одиночного модуля, после подключения устройства будут выведены аналогичные логи, свидетельствующие об успехе:

```
250705 -INFO-正在初始化MCP接入点: wss://2662r3426b.vicp.fun/mcp_e 
250705 -INFO-发送MCP接入点初始化消息
250705 -INFO-MCP接入点连接成功
250705 -INFO-MCP接入点初始化成功
250705 -INFO-统一工具处理器初始化完成
250705 -INFO-MCP接入点服务器信息: name=Calculator, version=1.9.4
250705 -INFO-MCP接入点支持的工具数量: 1
250705 -INFO-所有MCP接入点工具已获取，客户端准备就绪
250705 -INFO-工具缓存已刷新
250705 -INFO-当前支持的函数列表: [ 'get_time', 'get_lunar', 'play_music', 'get_weather', 'handle_exit_intent', 'calculator']
```
Если список содержит `'calculator'`, значит устройство сможет, на основе распознавания намерений, вызывать инструмент калькулятора.
