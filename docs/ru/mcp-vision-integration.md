# Руководство по использованию визуальной модели

Это руководство состоит из двух частей:
- Часть первая: запуск визуальной модели в одиночном режиме xiaozhi-server
- Часть вторая: как включить визуальную модель при запуске всех модулей

Перед включением визуальной модели необходимо подготовить три вещи:
- Вам понадобится устройство с камерой, для которого в репозитории 虾哥 уже реализована функция вызова камеры. Например, `立创·实战派ESP32-S3开发板`
- Версия прошивки вашего устройства должна быть обновлена до 1.6.6 или выше
- У вас уже должна работать базовая схема диалога

## Запуск визуальной модели в одиночном режиме xiaozhi-server

### Шаг 1. Проверка сети

Визуальная модель по умолчанию запускается на порту 8003.

Если вы запускаетесь через docker, убедитесь, что в вашем `docker-compose.yml` открыт порт `8003`. Если нет — обновите файл `docker-compose.yml` до последней версии.

Если вы запускаетесь из исходного кода, убедитесь, что файрвол пропускает порт `8003`.

### Шаг 2. Выбор визуальной модели

Откройте файл `data/.config.yaml` и укажите в `selected_module.VLLM` нужную визуальную модель. В настоящее время поддерживаются визуальные модели с интерфейсом типа `openai`. `ChatGLMVLLM` — одна из моделей, совместимых с `openai`.

```
selected_module:
  VAD: ..
  ASR: ..
  LLM: ..
  VLLM: ChatGLMVLLM
  TTS: ..
  Memory: ..
  Intent: ..
```

Предположим, мы используем `ChatGLMVLLM` в качестве визуальной модели. Тогда сначала нужно зайти на сайт [智谱AI](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) и получить ключ API. Если вы уже получали ключ ранее, можно использовать его повторно.

Добавьте в свой конфигурационный файл следующую конфигурацию. Если она уже есть — просто укажите свой api_key.

```
VLLM:
  ChatGLMVLLM:
    api_key: 你的api_key
```

### Шаг 3. Запуск службы xiaozhi-server

Если вы запускаетесь из исходного кода, введите команду запуска:
```
python app.py
```
Если вы запускаетесь через docker, перезапустите контейнер:
```
docker restart xiaozhi-esp32-server
```

После запуска в журнале будут выведены следующие строки.

```
2025-06-01 **** - OTA接口是           http://192.168.4.7:8003/xiaozhi/ota/
2025-06-01 **** - 视觉分析接口是        http://192.168.4.7:8003/mcp/vision/explain
2025-06-01 **** - Websocket地址是       ws://192.168.4.7:8000/xiaozhi/v1/
2025-06-01 **** - =======上面的地址是websocket协议地址，请勿用浏览器访问=======
2025-06-01 **** - 如想测试websocket请启动digital-human模块，打开浏览器交互测试
2025-06-01 **** - =============================================================
```

После запуска откройте в браузере ссылку `视觉分析接口` из журнала. Что выводится? Если у вас Linux и нет браузера, можно выполнить эту команду:
```
curl -i 你的视觉分析接口
```

В нормальном случае отобразится следующее:
```
MCP Vision 接口运行正常，视觉解释接口地址是：http://xxxx:8003/mcp/vision/explain
```

Обратите внимание: если вы развёртываете в публичной сети или через docker, обязательно измените в `data/.config.yaml` следующую конфигурацию:
```
server:
  vision_explain: http://你的ip或者域名:端口号/mcp/vision/explain
```

Почему? Потому что адрес интерфейса визуального объяснения должен быть выдан устройству. Если адрес локальный (LAN) или внутренний адрес docker, устройство не сможет до него добраться.

Предположим, ваш публичный адрес — `111.111.111.111`. Тогда `vision_explain` нужно настроить так:

```
server:
  vision_explain: http://111.111.111.111:8003/mcp/vision/explain
```

Если интерфейс MCP Vision работает нормально и вы проверили, что адрес `视觉解释接口地址`, выдаваемый на устройство, открывается в браузере, переходите к следующему шагу.

### Шаг 4. Активация устройством

Скажите устройству: «Пожалуйста, включи камеру и скажи, что ты видишь».

Следите за выводом журнала xiaozhi-server и проверяйте, нет ли ошибок.

## Как включить визуальную модель при запуске всех модулей

### Шаг 1. Проверка сети

Визуальная модель по умолчанию запускается на порту 8003.

Если вы запускаетесь через docker, убедитесь, что в вашем `docker-compose_all.yml` проброшен порт `8003`. Если нет — обновите файл `docker-compose_all.yml` до последней версии.

Если вы запускаетесь из исходного кода, убедитесь, что файрвол пропускает порт `8003`.

### Шаг 2. Проверка конфигурационного файла

Откройте файл `data/.config.yaml` и убедитесь, что структура вашего конфигурационного файла совпадает с `data/config_from_api.yaml`. Если есть отличия или отсутствуют какие-то пункты — дополните их.

### Шаг 3. Настройка ключа визуальной модели

Сначала нужно зайти на сайт [智谱AI](https://bigmodel.cn/usercenter/proj-mgmt/apikeys) и получить ключ API. Если вы уже получали ключ ранее, можно использовать его повторно.

Войдите в `智控台`, в верхнем меню нажмите `模型配置`, в левой панели выберите `视觉大语言模型`, найдите `VLLM_ChatGLMVLLM`, нажмите кнопку изменения, в открывшемся окне введите свой ключ в поле `API密钥` и нажмите «Сохранить».

После успешного сохранения перейдите к агенту, которого хотите протестировать, нажмите `配置角色` и в открывшемся содержимом проверьте, выбрана ли в `视觉大语言模型(VLLM)` та визуальная модель, которую вы только что настроили. Нажмите «Сохранить».
