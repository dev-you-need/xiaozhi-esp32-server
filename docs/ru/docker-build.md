# Способ локальной сборки docker-образа

В настоящее время этот проект использует функцию `автоматической сборки docker-образа` на `github`. Если вы используете опубликованный проектом образ, вам не нужно собирать образ самостоятельно — можете пропустить этот документ.

Если вы изменили исходный код и хотите развернуть и запустить проект с помощью `docker`, следуйте описанным ниже шагам:

## 1. Подготовка окружения

Установите docker:
```bash
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

## 2. Сборка образа

Когда вы внесли изменения в код и вам нужно собрать новый образ, выполните следующие шаги:

Подготовьте `ваше имя пользователя` и `новый номер версии`.
- `ваше имя пользователя` — это имя пользователя, зарегистрированное вами на `docker hub`, например `xiaozhi`. Конечно, если вам не нужно отправлять образ в `docker hub`, вы можете задать его произвольно.
- `новый номер версии` — это версия собираемого образа, например `1.2.3`. Вы можете задать её по своему усмотрению или использовать формат даты (например, `20260609`) — это в основном нужно, чтобы отличать её от версии, которая сейчас запущена, и чтобы в следующий раз легко вспомнить, когда была выполнена сборка. Номер не должен совпадать с версией, которая сейчас запущена на вашем компьютере.

Перейдите в корневую директорию проекта `xiaozhi-esp32-server` и соберите два образа: server и web:

```bash
cd корневая директория проекта

# Сборка образа server
docker build -f Dockerfile-server -t ваше_имя_пользователя/xiaozhi-esp32-server:новая_версия .

# Сборка образа web
docker build -f Dockerfile-web -t ваше_имя_пользователя/xiaozhi-esp32-server-web:новая_версия .

```

## 3. Изменение конфигурации docker-compose

```bash
cd main/xiaozhi-server
```

Отредактируйте файл `docker-compose_all.yml`, заменив версии образов на только что собранные:

```yaml
services:
  xiaozhi-esp32-server:
    image: ваше_имя_пользователя/xiaozhi-esp32-server:новая_версия   # замените на адрес вашего образа
    ...

  xiaozhi-esp32-server-web:
    image: ваше_имя_пользователя/xiaozhi-esp32-server-web:новая_версия   # замените на адрес вашего образа
    ...
```

## 4. Перезапуск сервиса

```bash
# Остановка старых контейнеров
docker compose -f docker-compose_all.yml down

# Запуск новых контейнеров
docker compose -f docker-compose_all.yml up -d
```

## 5. Проверка

Просмотрите логи, чтобы убедиться, что сервис запустился нормально:

```bash
# Просмотр логов server
docker logs -f -n 50 xiaozhi-esp32-server

# Просмотр логов web
docker logs -f -n 50 xiaozhi-esp32-server-web
```
