# Часто задаваемые вопросы ❓

### 1. Почему то, что я говорю, Xiaozhi распознаёт как много корейских, японских и английских слов? 🇰🇷

Рекомендация: проверьте, есть ли в `models/SenseVoiceSmall` файл `model.pt`.
Если его нет, его нужно скачать — см. [Загрузка файлов модели распознавания речи](Deployment.md#модель)

### 2. Почему возникает ошибка «TTS 任务出错 文件不存在» («Ошибка задачи TTS: файл не существует»)? 📁

Рекомендация: проверьте, правильно ли вы установили через `conda` библиотеки `libopus` и `ffmpeg`.

Если они не установлены, установите их:

```
conda install conda-forge::libopus
conda install conda-forge::ffmpeg
```

### 3. TTS часто завершается ошибкой, часто превышение времени ожидания ⏰

Рекомендация: если `EdgeTTS` часто завершается ошибкой, сначала проверьте, используете ли вы прокси (VPN). Если используете, попробуйте отключить прокси и повторить попытку;  
если вы используете TTS Doubao от Volcano Engine, при частых ошибках рекомендуется использовать платную версию, так как тестовая версия поддерживает только 2 одновременных подключения.

### 4. Через WiFi можно подключиться к собственному серверу, но в режиме 4G подключение не устанавливается 🔐

Причина: прошивка Xia Ge (虾哥) в режиме 4G требует защищённого соединения.

Решение: в настоящее время есть два способа решить эту проблему. Выберите любой:

1、Изменение кода. Решение по этому видео: https://www.bilibili.com/video/BV18MfTYoE85

2、Использование SSL-сертификата с настройкой nginx. См. руководство: https://icnt94i5ctj4.feishu.cn/docx/GnYOdMNJOoRCljx1ctecsj9cnRe

### 5. Как ускорить скорость отклика Xiaozhi в диалоге? ⚡

Проект по умолчанию настроен на экономичное решение; рекомендуется начинающим сначала использовать бесплатные модели по умолчанию, решив вопрос «чтобы работало», а затем оптимизировать «чтобы работало быстро».  
Если нужно повысить скорость отклика, попробуйте заменить компоненты. Начиная с версии `0.5.2` проект поддерживает потоковую конфигурацию, которая по сравнению с ранними версиями ускоряет отклик примерно на `2.5 секунды`, значительно улучшая пользовательский опыт.

| Название модуля | Полностью бесплатная настройка для начинающих | Потоковая конфигурация |
|:---:|:---:|:---:|
| ASR (распознавание речи) | FunASR (локальный) | 👍XunfeiStreamASR (потоковый от iFlytek) |
| LLM (большая языковая модель) | glm-4-flash (Zhipu) | 👍qwen-flash (Aliyun Bailian) |
| VLLM (визуальная большая модель) | glm-4v-flash (Zhipu) | 👍qwen3.5-flash (Aliyun Bailian) |
| TTS (синтез речи) | EdgeTTS (Microsoft) | 👍HuoshanDoubleStreamTTS (потоковый от Volcano) |
| Intent (распознавание намерений) | function_call (вызов функций) | function_call (вызов функций) |
| Memory (функция памяти) | mem_local_short (локальная краткосрочная память) | mem_local_short (локальная краткосрочная память) |

Если вас интересует время работы каждого компонента, ознакомьтесь с [отчётом о тестировании производительности компонентов Xiaozhi](https://github.com/xinnan-tech/xiaozhi-performance-research) — вы можете по методике из отчёта провести фактическое тестирование в своей среде.

### 6. Я говорю медленно, а Xiaozhi постоянно перебивает меня во время пауз 🗣️

Рекомендация: найдите в конфигурационном файле следующий раздел и увеличьте значение `min_silence_duration_ms` (например, измените на `1000`):

```yaml
VAD:
  SileroVAD:
    threshold: 0.5
    model_dir: models/snakers4_silero-vad
    min_silence_duration_ms: 700  # 如果说话停顿较长，可将此值调大
```
