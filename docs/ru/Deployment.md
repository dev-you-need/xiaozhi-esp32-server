# Способ 1: Docker, запуск только Server

Начиная с версии `0.8.2`, выпускаемые проектом docker-образы поддерживают только архитектуру `x86`. Если вам нужно развернуть проект на CPU с архитектурой `arm64`, следуйте [этому руководству](docker-build.md), чтобы скомпилировать `образ для arm64` на своей машине.

## 1. Установка docker

Если docker еще не установлен на вашем компьютере, можно воспользоваться этим руководством: [установка docker](https://www.runoob.com/docker/ubuntu-docker-install.html)

После установки docker продолжайте.

### 1.1 Ручное развертывание

#### 1.1.1 Создание каталога

После установки docker вам нужно выбрать каталог для файлов конфигурации проекта, например можно создать папку с именем `xiaozhi-server`.

После создания каталога вам нужно создать внутри `xiaozhi-server` папки `data` и `models`, а внутри `models` — еще одну папку `SenseVoiceSmall`.

Итоговая структура каталогов выглядит так:

```
xiaozhi-server
  ├─ data
  ├─ models
     ├─ SenseVoiceSmall
```

#### 1.1.2 Загрузка модели распознавания речи

Вам нужно загрузить файл модели распознавания речи, поскольку по умолчанию проект использует локальное автономное распознавание речи. Скачать можно так:
[Перейти к загрузке модели распознавания речи](#модель)

После загрузки возвращайтесь к этому руководству.

#### 1.1.3 Загрузка файлов конфигурации

Вам нужно загрузить два файла конфигурации: `docker-compose.yaml` и `config.yaml`. Эти файлы нужно скачать из репозитория проекта.

##### 1.1.3.1 Загрузка docker-compose.yaml

Откройте в браузере [эту ссылку](../../main/xiaozhi-server/docker-compose.yml).

В правой части страницы найдите кнопку с названием `RAW`, рядом с кнопкой `RAW` найдите значок загрузки, нажмите кнопку загрузки и скачайте файл `docker-compose.yml`. Сохраните файл в ваш
`xiaozhi-server`.

После загрузки возвращайтесь к этому руководству.

##### 1.1.3.2 Создание config.yaml

Откройте в браузере [эту ссылку](../../main/xiaozhi-server/config.yaml).

В правой части страницы найдите кнопку с названием `RAW`, рядом с кнопкой `RAW` найдите значок загрузки, нажмите кнопку загрузки и скачайте файл `config.yaml`. Сохраните файл в папку
`data` внутри `xiaozhi-server`, затем переименуйте файл `config.yaml` в `.config.yaml`.

После загрузки файлов конфигурации проверим, что весь `xiaozhi-server` выглядит так:

```
xiaozhi-server
  ├─ docker-compose.yml
  ├─ data
    ├─ .config.yaml
  ├─ models
     ├─ SenseVoiceSmall
       ├─ model.pt
```

Если структура каталогов у вас такая же — продолжайте дальше. Если нет, еще раз внимательно проверьте, не пропустили ли вы какой-то шаг.

## 2. Настройка файлов проекта

Далее программа пока не может запуститься — нужно настроить, какие модели вы будете использовать. Можете посмотреть это руководство:
[Перейти к настройке файлов проекта](#настройка-проекта)

После настройки файлов проекта возвращайтесь к этому руководству.

## 3. Выполнение docker-команд

Откройте командную строку, с помощью инструмента `Терминал` или `Командная строка` перейдите в ваш `xiaozhi-server` и выполните следующую команду

```
docker compose up -d
```

После выполнения выполните следующую команду, чтобы просмотреть журнал.

```
docker logs -f xiaozhi-esp32-server
```

Теперь следите за журналом, по этому руководству можно определить, успешно ли запуск. [Перейти к проверке состояния запуска](#проверка-состояния-запуска)

## 5. Обновление версии

Если позже захотите обновить версию, можно сделать так

5.1 Сделайте резервную копию файла `.config.yaml` из папки `data`, ключевые настройки потом нужно будет скопировать в новый файл `.config.yaml`.
Обратите внимание: ключи нужно копировать по одному, не перезаписывайте файл целиком. Потому что в новом файле `.config.yaml` могут появиться новые параметры, которых нет в старом `.config.yaml`.

5.2 Выполните следующие команды

```
docker stop xiaozhi-esp32-server
docker rm xiaozhi-esp32-server
docker stop xiaozhi-esp32-server-web
docker rm xiaozhi-esp32-server-web
docker rmi ghcr.nju.edu.cn/xinnan-tech/xiaozhi-esp32-server:server_latest
docker rmi ghcr.nju.edu.cn/xinnan-tech/xiaozhi-esp32-server:web_latest
```

5.3 Заново выполните развертывание способом docker

# Способ 2: Локальный исходный код, запуск только Server

## 1.Установка базового окружения

Проект использует `conda` для управления зависимостями окружения. Если установить `conda` неудобно, нужно в зависимости от операционной системы установить `libopus` и `ffmpeg`.
Если вы решили использовать `conda`, то после установки выполните следующие команды.

Важное замечание! Пользователи Windows могут управлять окружением с помощью установки `Anaconda`. После установки `Anaconda` нажмите `Пуск`, введите ключевое слово `anaconda`,
найдите `Anaconda Prompt` и запустите его от имени администратора. Как показано на рисунке.

![conda_prompt](../images/conda_env_1.png)

После запуска, если вы видите слово (base) в начале командной строки, значит, вы успешно вошли в окружение `conda`. Тогда можно выполнить следующие команды.

![conda_env](../images/conda_env_2.png)

```
conda remove -n xiaozhi-esp32-server --all -y
conda create -n xiaozhi-esp32-server python=3.10 -y
conda activate xiaozhi-esp32-server

# 添加清华源通道
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge

conda install libopus -y
conda install ffmpeg -y

# 在 Linux 环境下进行部署时,如出现类似缺失 libiconv.so.2 动态库的报错 请通过以下命令进行安装
conda install libiconv -y
```

Обратите внимание: приведенные выше команды не выполняются успешно «одним махом» — нужно выполнять их шаг за шагом, и после каждого шага проверять выводимый журнал и убеждаться, что все прошло успешно.

## 2.Установка зависимостей проекта

Сначала нужно загрузить исходный код проекта, его можно скачать командой `git clone`, если вы не знакомы с командой `git clone`.

Можете открыть в браузере этот адрес `https://github.com/xinnan-tech/xiaozhi-esp32-server.git`

После открытия найдите на странице зеленую кнопку с надписью `Code`, нажмите на нее, затем вы увидите кнопку `Download ZIP`.

Нажмите ее, чтобы скачать архив с исходным кодом проекта. После загрузки на компьютер распакуйте его, при этом имя может быть `xiaozhi-esp32-server-main`
Вам нужно переименовать его в `xiaozhi-esp32-server`, в этой папке перейдите в папку `main`, затем в `xiaozhi-server` — запомните этот каталог `xiaozhi-server`.

```
# 继续使用conda环境
conda activate xiaozhi-esp32-server
# 进入到你的项目根目录，再进入main/xiaozhi-server
cd main/xiaozhi-server
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
pip install -r requirements.txt
```

## 3.Загрузка модели распознавания речи

Вам нужно загрузить файл модели распознавания речи, поскольку по умолчанию проект использует локальное автономное распознавание речи. Скачать можно так:
[Перейти к загрузке модели распознавания речи](#модель)

После загрузки возвращайтесь к этому руководству.

## 4.Настройка файлов проекта

Далее программа пока не может запуститься — нужно настроить, какие модели вы будете использовать. Можете посмотреть это руководство:
[Перейти к настройке файлов проекта](#настройка-проекта)

## 5.Запуск проекта

```
# 确保在xiaozhi-server目录下执行
conda activate xiaozhi-esp32-server
python app.py
```
Теперь следите за журналом, по этому руководству можно определить, успешно ли запуск. [Перейти к проверке состояния запуска](#проверка-состояния-запуска)


# Сводка

## Настройка проекта

Если в вашем каталоге `xiaozhi-server` нет папки `data`, вам нужно создать каталог `data`.
Если в папке `data` нет файла `.config.yaml`, есть два способа, выберите любой:

Первый способ: можно скопировать файл `config.yaml` из каталога `xiaozhi-server` в `data` и переименовать его в `.config.yaml`. Изменения вносите в этот файл.

Второй способ: можно вручную создать пустой файл `.config.yaml` в каталоге `data`, а затем добавить в этот файл необходимые параметры конфигурации. Система в первую очередь читает конфигурацию из файла `.config.yaml`, а если какого-то параметра там нет, система автоматически загрузит конфигурацию из файла `config.yaml` в каталоге `xiaozhi-server`. Рекомендуется использовать именно этот способ — он самый простой.

- LLM по умолчанию — `ChatGLMLLM`, вам нужно указать ключ, потому что для их моделей, хотя они и есть бесплатные, все равно требуется зарегистрировать ключ на [официальном сайте](https://bigmodel.cn/usercenter/proj-mgmt/apikeys), чтобы запустить их.

Ниже приведен пример самой простой конфигурации `.config.yaml`, с которой проект запустится

```
server:
  websocket: ws://你的ip或者域名:端口号/xiaozhi/v1/
prompt: |
  我是一个叫小智/小志的台湾女孩，说话机车，声音好听，习惯简短表达，爱用网络梗。
  我的男朋友是一个程序员，梦想是开发出一个机器人，能够帮助人们解决生活中的各种问题。
  我是一个喜欢哈哈大笑的女孩，爱东说西说吹牛，不合逻辑的也照吹，就要逗别人开心。
  请你像一个人一样说话，请勿返回配置xml及其他特殊字符。

selected_module:
  LLM: DoubaoLLM

LLM:
  ChatGLMLLM:
    api_key: xxxxxxxxxxxxxxx.xxxxxx
```

Рекомендуется сначала запустить самую простую конфигурацию, а затем прочитать инструкцию по конфигурации в `xiaozhi/config.yaml`.
Например, если хотите сменить модель, достаточно изменить конфигурацию в разделе `selected_module`.

## Модель

Для распознавания речи проект по умолчанию использует модель `SenseVoiceSmall` для преобразования речи в текст. Поскольку модель большая, ее нужно загрузить отдельно, после загрузки поместите файл `model.pt`
в каталог
`models/SenseVoiceSmall`. Выберите один из двух вариантов загрузки ниже.

- Вариант 1: загрузка с ModelScope (Ali ModelScope) [SenseVoiceSmall](https://modelscope.cn/models/iic/SenseVoiceSmall/resolve/master/model.pt)
- Вариант 2: загрузка с Baidu Netdisk [SenseVoiceSmall](https://pan.baidu.com/share/init?surl=QlgM58FHhYv1tFnUT_A8Sg&pwd=qvna) код извлечения:
  `qvna`

## Проверка состояния запуска

Если вы видите журнал, похожий на приведенный ниже, это признак успешного запуска сервиса проекта.

```
250427 13:04:20[0.3.11_SiFuChTTnofu][__main__]-INFO-OTA接口是           http://192.168.4.123:8003/xiaozhi/ota/
250427 13:04:20[0.3.11_SiFuChTTnofu][__main__]-INFO-Websocket地址是     ws://192.168.4.123:8000/xiaozhi/v1/
250427 13:04:20[0.3.11_SiFuChTTnofu][__main__]-INFO-=======上面的地址是websocket协议地址，请勿用浏览器访问=======
250427 13:04:20[0.3.11_SiFuChTTnofu][__main__]-INFO-如想测试websocket请启动digital-human模块，打开浏览器交互测试
250427 13:04:20[0.3.11_SiFuChTTnofu][__main__]-INFO-=======================================================
```

Обычно, если вы запускаете проект из исходного кода, в журнале будут указаны адреса ваших интерфейсов.
Но если вы развернули проект через docker, адреса интерфейсов, указанные в журнале, не будут реальными адресами интерфейсов.

Самый правильный способ — определить адрес интерфейса по локальному IP-адресу компьютера.
Если, например, локальный IP-адрес вашего компьютера `192.168.1.25`, то адрес вашего интерфейса будет: `ws://192.168.1.25:8000/xiaozhi/v1/`, а соответствующий OTA-адрес: `http://192.168.1.25:8003/xiaozhi/ota/`.

Эта информация очень полезна, она понадобится позже при `компиляции прошивки esp32`.

Далее вы можете приступить к настройке вашего устройства esp32: можно `скомпилировать прошивку esp32 самостоятельно`, а можно настроить использование `прошивки версии 1.6.1 и выше, скомпилированной Ся Гэ`. Выберите один из двух вариантов

1、 [Скомпилировать собственную прошивку esp32](firmware-build.md).

2、 [Настроить пользовательский сервер на основе готовой прошивки Ся Гэ](firmware-setting.md).
