# Руководство по развёртыванию и использованию точки подключения MCP

Это руководство состоит из 3 частей
- 1. Как развернуть сервис точки подключения MCP
- 2. Как настроить точку подключения MCP при полном развёртывании модулей
- 3. Как настроить точку подключения MCP при развёртывании одного модуля

# 1. Как развернуть сервис точки подключения MCP

## Шаг 1. Скачайте исходный код проекта точки подключения MCP

Откройте в браузере [адрес проекта точки подключения MCP](https://github.com/xinnan-tech/mcp-endpoint-server)

На странице найдите зелёную кнопку с надписью `Code`, нажмите на неё, затем вы увидите кнопку `Download ZIP`.

Нажмите её, чтобы скачать архив с исходным кодом проекта. После скачивания распакуйте архив; папка может называться `mcp-endpoint-server-main`.
Вам нужно переименовать её в `mcp-endpoint-server`.

## Шаг 2. Запустите программу
Это очень простой проект, рекомендуется запускать его через docker. Но если вы не хотите использовать docker, можно запустить из исходного кода по [этой странице](https://github.com/xinnan-tech/mcp-endpoint-server/blob/main/README_dev.md). Ниже описан способ запуска через docker

```
# перейдите в корневой каталог исходного кода проекта
cd mcp-endpoint-server

# очистите кэш
docker compose -f docker-compose.yml down
docker stop mcp-endpoint-server
docker rm mcp-endpoint-server
docker rmi ghcr.nju.edu.cn/xinnan-tech/mcp-endpoint-server:latest

# запустите docker-контейнер
docker compose -f docker-compose.yml up -d
# просмотр логов
docker logs -f mcp-endpoint-server
```

В этот момент в логах появится примерно следующее
```
250705 INFO-=====下面的地址分别是智控台/单模块MCP接入点地址====
250705 INFO-智控台MCP参数配置: http://172.22.0.2:8004/mcp_endpoint/health?key=abc
250705 INFO-单模块部署MCP接入点: ws://172.22.0.2:8004/mcp_endpoint/mcp/?token=def
250705 INFO-=====请根据具体部署选择使用，请勿泄露给任何人======
```

Сначала скопируйте адреса и сохраните их в черновик. Узнайте локальный IP-адрес вашего компьютера в сети, например, у моего компьютера он `192.168.1.25`, тогда
исходные адреса моих интерфейсов
```
智控台MCP参数配置: http://172.22.0.2:8004/mcp_endpoint/health?key=abc
单模块部署MCP接入点: ws://172.22.0.2:8004/mcp_endpoint/mcp/?token=def
```
нужно заменить на
```
智控台MCP参数配置: http://192.168.1.25:8004/mcp_endpoint/health?key=abc
单模块部署MCP接入点: ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=def
```

После замены откройте `智控台MCP参数配置` напрямую в браузере. Если в браузере появится примерно такой код, значит всё получилось.
```
{"result":{"status":"success","connections":{"tool_connections":0,"robot_connections":0,"total_connections":0}},"error":null,"id":null,"jsonrpc":"2.0"}
```

Сохраните эти два `адреса интерфейсов`, они понадобятся на следующем шаге.

# 2. Как настроить точку подключения MCP при полном развёртывании модулей
Сначала необходимо включить функцию точки подключения MCP. В панели управления нажмите `参数字典` в верхней части страницы, в выпадающем меню выберите страницу `系统功能配置`. На странице отметьте галочкой `MCP接入点` и нажмите `保存配置`. На странице `角色配置` нажмите кнопку `编辑功能` — там появится функция `mcp接入点`.

Если у вас полное развёртывание модулей, войдите в панель управления под учётной записью администратора, нажмите `参数字典` в верхней части страницы и выберите функцию `参数管理`.

Затем найдите параметр `server.mcp_endpoint` — сейчас его значение должно быть `null`.
Нажмите кнопку изменения, вставьте полученный на предыдущем шаге `智控台MCP参数配置` в поле `参数值` и сохраните.

Если сохранение прошло успешно, значит всё в порядке, и можно проверить результат в агенте. Если сохранение не удалось, значит панель управления не может получить доступ к точке подключения MCP — с большой вероятностью это сетевой файрвол или неверно указан локальный IP-адрес.

# 3. Как настроить точку подключения MCP при развёртывании одного модуля

Если у вас развёртывание одного модуля, найдите файл конфигурации `data/.config.yaml`.
Найдите в конфигурации `mcp_endpoint`; если параметр не найден, добавьте настройку `mcp_endpoint`. Например, у меня так
```
server:
  websocket: ws://你的ip或者域名:端口号/xiaozhi/v1/
  http_port: 8002
log:
  log_level: INFO

# 此处可能还更多配置..

mcp_endpoint: 你的接入点websocket地址
```
Теперь вставьте полученный в разделе «Как развернуть сервис точки подключения MCP» адрес `单模块部署MCP接入点` в поле `mcp_endpoint`. Например, так

```
server:
  websocket: ws://你的ip或者域名:端口号/xiaozhi/v1/
  http_port: 8002
log:
  log_level: INFO

# 此处可能还更多配置

mcp_endpoint: ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=def
```

После настройки при запуске одного модуля будут выведены следующие логи.
```
250705[__main__]-INFO-初始化组件: vad成功 SileroVAD
250705[__main__]-INFO-初始化组件: asr成功 FunASRServer
250705[__main__]-INFO-OTA接口是          http://192.168.1.25:8002/xiaozhi/ota/
250705[__main__]-INFO-视觉分析接口是     http://192.168.1.25:8002/mcp/vision/explain
250705[__main__]-INFO-mcp接入点是        ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=abc
250705[__main__]-INFO-Websocket地址是    ws://192.168.1.25:8000/xiaozhi/v1/
250705[__main__]-INFO-=======上面的地址是websocket协议地址，请勿用浏览器访问=======
250705[__main__]-INFO-如想测试websocket请启动digital-human模块，打开浏览器交互测试
250705[__main__]-INFO-=============================================================
```

Как показано выше, если в логах примерно появилась строка `mcp接入点是` с адресом `ws://192.168.1.25:8004/mcp_endpoint/mcp/?token=abc`, значит настройка прошла успешно.
