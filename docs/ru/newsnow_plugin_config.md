# Руководство по настройке источников новостей плагина get_news_from_newsnow

## Обзор

Плагин `get_news_from_newsnow` теперь поддерживает динамическую настройку источников новостей через веб-интерфейс управления, без необходимости изменять код. Пользователи могут настраивать разные источники новостей для каждого агента в панели управления.

## Способы настройки

### 1. Настройка через веб-интерфейс управления (рекомендуется)

1. Войдите в панель управления
2. Перейдите на страницу «Настройка роли»
3. Выберите агента, которого нужно настроить
4. Нажмите кнопку «Редактировать функции»
5. В области настройки параметров справа найдите плагин «Агрегатор новостей newsnow»
6. В поле «Настройка источников новостей» введите китайские названия, разделённые точкой с запятой

### 2. Способ через конфигурационный файл

Настройте в файле `config.yaml`:

```yaml
plugins:
  get_news_from_newsnow:
    url: "https://newsnow.busiyi.world/api/s?id="
    news_sources: "澎湃新闻;百度热搜;财联社;微博;抖音"
```

## Формат настройки источников новостей

Настройка источников новостей задаётся китайскими названиями, разделёнными точкой с запятой, в формате:

```
китайское_название1;китайское_название2;китайское_название3
```

### Пример настройки

```
澎湃新闻;百度热搜;财联社;微博;抖音;知乎;36氪
```

## Настройка по умолчанию

Если источники новостей не настроены, плагин будет использовать следующую конфигурацию по умолчанию:

```
澎湃新闻;百度热搜;财联社
```

## Инструкция по использованию

1. **Настройка источников новостей**: задайте китайские названия источников новостей в веб-интерфейсе или конфигурационном файле, разделяя их точкой с запятой
2. **Вызов плагина**: пользователь может сказать «Озвучь новости» или «Получи новости»
3. **Указание источника новостей**: пользователь может сказать «Озвучи новости 澎湃新闻» или «Получи 百度热搜»
4. **Получение подробностей**: пользователь может сказать «Расскажи подробнее об этой новости»

## Принцип работы

1. Плагин принимает в качестве параметра китайское название (например, «澎湃新闻»)
2. На основе настроенного списка источников новостей преобразует китайское название в соответствующий английский идентификатор (например, «thepaper»)
3. Использует английский идентификатор для вызова API и получения данных новостей
4. Возвращает содержимое новостей пользователю

## Обратите внимание

1. Настроенные китайские названия должны полностью совпадать с названиями, определёнными в CHANNEL_MAP
2. После изменения настройки необходимо перезапустить сервис или перезагрузить конфигурацию
3. Если настроенный источник новостей недействителен, плагин автоматически использует источники новостей по умолчанию
4. Между несколькими источниками новостей используйте английскую точку с запятой (;), не используйте китайскую точку с запятой (；)
