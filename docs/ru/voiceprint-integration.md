# Руководство по включению распознавания голосовых отпечатков

Это руководство состоит из 3 частей:
- 1. Как развернуть сервис распознавания голосовых отпечатков
- 2. Как настроить интерфейс распознавания голосовых отпечатков при полном развёртывании модулей
- 3. Как настроить распознавание голосовых отпечатков при минимальном развёртывании

# 1. Как развернуть сервис распознавания голосовых отпечатков

## Шаг 1. Скачайте исходный код проекта распознавания голосовых отпечатков

Откройте в браузере [страницу проекта распознавания голосовых отпечатков](https://github.com/xinnan-tech/voiceprint-api)

На странице найдите зелёную кнопку с надписью `Code`, нажмите её, затем нажмите кнопку `Download ZIP`.

Нажмите её, чтобы скачать архив с исходным кодом проекта. После скачивания на компьютер распакуйте архив — папка может называться `voiceprint-api-main`
Вам нужно переименовать её в `voiceprint-api`.

## Шаг 2. Создайте базу данных и таблицы

Распознавание голосовых отпечатков зависит от базы данных `mysql`. Если вы ранее уже развернули `панель управления`, значит, `mysql` у вас уже установлен. Можно использовать её совместно.

Попробуйте выполнить на хост-машине команду `telnet`, чтобы проверить, доступен ли порт `3306` `mysql`.
```
telnet 127.0.0.1 3306
```
Если порт 3306 доступен, пропустите следующий текст и переходите сразу к шагу 3.

Если доступа нет, вспомните, как вы устанавливали `mysql`.

Если mysql был установлен вами вручную из установочного пакета, значит, для `mysql` настроена сетевая изоляция. Возможно, сначала нужно решить проблему доступа к порту `3306` `mysql`.

Если `mysql` был установлен через `docker-compose_all.yml` этого проекта. Найдите файл `docker-compose_all.yml`, с помощью которого вы тогда создавали базу данных, и измените следующее:

До изменения
```
  xiaozhi-esp32-server-db:
    ...
    networks:
      - default
    expose:
      - "3306:3306"
```

После изменения
```
  xiaozhi-esp32-server-db:
    ...
    networks:
      - default
    ports:
      - "3306:3306"
```

Обратите внимание: `expose` у `xiaozhi-esp32-server-db` меняется на `ports`. После изменения нужно перезапустить. Команды перезапуска mysql:

```
# 进入你docker-compose_all.yml所在的文件夹，例如我的是xiaozhi-server
cd xiaozhi-server
docker compose -f docker-compose_all.yml down
docker compose -f docker-compose.yml up -d
```

После запуска снова выполните на хост-машине команду `telnet`, чтобы проверить, доступен ли порт `3306` `mysql`.
```
telnet 127.0.0.1 3306
```
Как правило, после этого порт станет доступен.

## Шаг 3. Создайте базу данных и таблицы
Если хост-машина нормально подключается к базе данных mysql, создайте в mysql базу данных с именем `voiceprint_db` и таблицу `voiceprints`.

```
CREATE DATABASE voiceprint_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE voiceprint_db;

CREATE TABLE voiceprints (
    id INT AUTO_INCREMENT PRIMARY KEY,
    speaker_id VARCHAR(255) NOT NULL UNIQUE,
    feature_vector LONGBLOB NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_speaker_id (speaker_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## Шаг 4. Настройте подключение к базе данных

Перейдите в папку `voiceprint-api` и создайте в ней папку с именем `data`.

Скопируйте файл `voiceprint.yaml` из корневого каталога `voiceprint-api` в папку `data` и переименуйте его в `.voiceprint.yaml`

Далее вам нужно в первую очередь настроить подключение к базе данных в `.voiceprint.yaml`.

```
mysql:
  host: "127.0.0.1"
  port: 3306
  user: "root"
  password: "your_password"
  database: "voiceprint_db"
```

Внимание! Поскольку сервис распознавания голосовых отпечатков развёрнут через docker, в `host` нужно указать `локальный IP-адрес машины, где находится mysql`.

## Шаг 5. Запустите программу
Это очень простой проект, рекомендуется запускать через docker. Но если вы не хотите использовать docker, можно запустить из исходного кода, как описано [на этой странице](https://github.com/xinnan-tech/voiceprint-api/blob/main/README.md). Ниже — способ запуска через docker.

```
# 进入本项目源码根目录
cd voiceprint-api

# 清除缓存
docker compose -f docker-compose.yml down
docker stop voiceprint-api
docker rm voiceprint-api
docker rmi ghcr.nju.edu.cn/xinnan-tech/voiceprint-api:latest

# 启动docker容器
docker compose -f docker-compose.yml up -d
# 查看日志
docker logs -f voiceprint-api
```

В этот момент в логах появится вывод примерно следующего вида

# 2. Как настроить распознавание голосовых отпечатков при полном развёртывании модулей

## Шаг 1. Настройка интерфейса
Сначала включите функцию распознавания голосовых отпечатков. В панели управления нажмите `Словарь параметров` вверху и в выпадающем меню выберите страницу `Настройка системных функций`. На странице отметьте галочкой `Распознавание голосовых отпечатков` и нажмите `Сохранить настройки`. После этого на карточке создания нового агента появится кнопка `Распознавание голосовых отпечатков`.

Если у вас полное развёртывание модулей, войдите в панель управления под учётной записью администратора, нажмите `Словарь параметров` вверху и выберите функцию `Управление параметрами`.

Затем найдите параметр `server.voice_print` — сейчас его значение должно быть `null`.
Нажмите кнопку изменения, вставьте `адрес интерфейса распознавания голоса`, полученный на предыдущем шаге, в `Значение параметра` и сохраните.

Если сохранение прошло успешно, значит, всё в порядке, и можно переходить в агента, чтобы проверить результат. Если нет — панель управления не может обратиться к сервису распознавания голосовых отпечатков; с большой вероятностью это сетевой фаервол или неверно указанный локальный IP-адрес.

## Шаг 2. Настройте режим памяти агента

Зайдите в настройки роли вашего агента и установите память в `локальную краткосрочную память`, обязательно включите `Отправка текста + голоса`.

## Шаг 3. Поговорите со своим агентом

Включите устройство и поговорите с ним в нормальном темпе и тоне.

## Шаг 4. Настройте голосовой отпечаток

В панели управления на странице `Управление агентами` на панели агента есть кнопка `Распознавание голосовых отпечатков` — нажмите её. Внизу есть кнопка `Добавить`. Так можно зарегистрировать голосовой отпечаток речи конкретного человека.
В открывшемся окне рекомендуется заполнить атрибут `Описание` — это может быть профессия, характер, увлечения человека. Это поможет агенту анализировать и лучше понимать говорящего.

## Шаг 3. Поговорите со своим агентом

Включите устройство и спросите: «Знаешь, кто я?» Если агент может ответить, значит, функция распознавания голосовых отпечатков работает.

# 3. Как настроить распознавание голосовых отпечатков при минимальном развёртывании

## Шаг 1. Настройка интерфейса
Откройте файл `xiaozhi-server/data/.config.yaml` (если его нет — создайте) и добавьте/измените следующее:

```
# 声纹识别配置
voiceprint:
  # 声纹接口地址
  url: 你的声纹接口地址
  # 说话人配置：speaker_id,名称,描述
  speakers:
    - "test1,张三,张三是一个程序员"
    - "test2,李四,李四是一个产品经理"
    - "test3,王五,王五是一个设计师"
```

Вставьте `адрес интерфейса распознавания голоса`, полученный на предыдущем шаге, в поле `url`. Затем сохраните.

Параметр `speakers` добавляется по необходимости. Обратите внимание на параметр `speaker_id` — он понадобится при регистрации голосовых отпечатков ниже.

## Шаг 2. Регистрация голосового отпечатка
Если сервис распознавания голосовых отпечатков уже запущен, откройте `http://localhost:8005/voiceprint/docs` в браузере, чтобы посмотреть документацию API; здесь описано только, как использовать API регистрации голосовых отпечатков.

Адрес API регистрации голосовых отпечатков — `http://localhost:8005/voiceprint/register`, метод запроса — POST.

В заголовке запроса нужен Bearer Token — это часть `声纹接口地址` после `?key=`, например, если мой адрес регистрации голоса `http://127.0.0.1:8005/voiceprint/health?key=abcd`, то мой token — `abcd`.

Тело запроса содержит идентификатор говорящего (speaker_id) и аудиофайл WAV (file), пример запроса:

```
curl -X POST \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -F "speaker_id=your_speaker_id_here" \
  -F "file=@/path/to/your/file" \
  http://localhost:8005/voiceprint/register
```

 Здесь `file` — аудиофайл с речью регистрируемого говорящего, `speaker_id` должен совпадать с `speaker_id`, указанным на шаге 1 настройки интерфейса. Например, мне нужно зарегистрировать голосовой отпечаток 张三 (Чжан Саня); в `.config.yaml` для 张三 указан `speaker_id` `test1`, значит, при регистрации его голосового отпечатка в теле запроса в поле `speaker_id` указываю `test1`, а в `file` — аудиофайл с фрагментом речи 张三.

 ## Шаг 3. Запуск сервиса

Запустите сервер Сяочжи и сервис распознавания голосовых отпечатков — всё готово к работе.
