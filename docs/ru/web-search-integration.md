# Руководство по использованию плагина веб-поиска

## Краткое описание

Плагин веб-поиска `web_search` поддерживает поиск информации в интернете в реальном времени в ходе диалога и возвращает результаты. Плагин поддерживает два источника поиска: Metaso и Tavily — пользователь может выбрать любой из них.

## Руководство по получению API Key

В настоящее время мы адаптировали поиск `Metaso` и поиск `Tavily`.
- Поиск Tavily: 1000 бесплатных запросов в месяц.
- Поиск Metaso: имеет довольно качественные китайские источники данных.

## Руководство по получению API Key

### Способ 1: использование поиска Metaso

- Перейдите на страницу [Metaso Search API](https://metaso.cn/search-api/api-keys), зарегистрируйтесь и войдите в аккаунт
- На странице управления API-ключами нажмите «Создать новый ключ»
- Скопируйте сгенерированный API Key (с префиксом `mk-`) — это ключевая информация, необходимая для конфигурации

### Способ 2: использование поиска Tavily

- Перейдите в [консоль Tavily](https://app.tavily.com/home), зарегистрируйтесь и войдите в аккаунт
- Создайте API Key в консоли
- Скопируйте сгенерированный API Key (с префиксом `tvly-`) — это ключевая информация, необходимая для конфигурации

## Способы конфигурации

### Способ 1. Развёртывание через панель управления (рекомендуется)

- Войдите в панель управления
- Перейдите на страницу «Настройка роли» и выберите агента, которого нужно настроить
- Нажмите кнопку «Редактировать функции» и в области настройки параметров справа найдите плагин «Веб-поиск»
- Отметьте «Веб-поиск»
- Укажите источник поиска (`metaso` или `tavily`) и введите соответствующий `API Key` в конфигурационный пункт
- Сохраните конфигурацию, а затем сохраните конфигурацию агента

### Способ 2. Развёртывание одиночного модуля xiaozhi-server

Настройте в файле `data/.config.yaml`:

- Укажите источник поиска в `provider`, допустимые значения — `metaso` или `tavily`
- Введите полученный API Key в `api_key`

```yaml
plugins:
  web_search:
    provider: "metaso"
    api_key: "ваш API Key"
```

Если нужно настроить количество возвращаемых результатов и описание инструмента, дополнительно укажите `max_results` и `description`:

```yaml
plugins:
  web_search:
    provider: "metaso"
    description: "Инструмент веб-поиска. Используйте этот инструмент, когда пользователю явно нужно задать вопрос, требующий поиска в интернете."
    max_results: 5
    api_key: "ваш API Key"
```

Также убедитесь, что в списке `functions` включён `web_search`:

```yaml
plugins:
  functions:
    - web_search
```

После завершения настройки перезапустите сервис, чтобы изменения вступили в силу.
