# Способ 1: Docker, запуск всех модулей
Начиная с версии `0.8.2`, выпускаемые проектом docker-образы поддерживают только архитектуру `x86`. Если вам нужно развернуть проект на CPU с архитектурой `arm64`, следуйте [этому руководству](docker-build.md), чтобы скомпилировать `образ для arm64` на своей машине.

## 1. Установка docker

Если docker еще не установлен на вашем компьютере, можно воспользоваться этим руководством: [установка docker](https://www.runoob.com/docker/ubuntu-docker-install.html)

Для установки всех модулей через docker есть два способа: можно [использовать простой скрипт](./Deployment_all.md#11-простой-скрипт) (автор [@VanillaNahida](https://github.com/VanillaNahida))
Скрипт автоматически загрузит необходимые файлы и файлы конфигурации, а можно использовать [ручное развертывание](./Deployment_all.md#12-ручное-развертывание) и собрать все с нуля.



### 1.1 Простой скрипт
Развертывание простое, можно посмотреть [видеоурок](https://www.bilibili.com/video/BV17bbvzHExd/), текстовая версия руководства ниже:
> [!NOTE]  
> Пока поддерживается только автоматическое развертывание на сервере Ubuntu, другие системы не проверялись, возможны странные баги

Подключитесь к серверу по SSH и выполните следующий скрипт с правами root
```bash
sudo bash -c "$(wget -qO- https://ghfast.top/https://raw.githubusercontent.com/xinnan-tech/xiaozhi-esp32-server/main/docker-setup.sh)"
```

Скрипт автоматически выполнит следующие действия:
> 1. Установит Docker
> 2. Настроит источники образов
> 3. Загрузит/получит образы
> 4. Загрузит файлы модели распознавания речи
> 5. Проведёт через начальную настройку сервера
>

После выполнения и простой настройки обратитесь к [4. Запуск программы](#4-запуск-программы) и [5. Перезапуск xiaozhi-esp32-server](#5перезапуск-xiaozhi-esp32-server), где упомянуты 3 самых важных дела; после выполнения этих трех настроек системой можно пользоваться.

### 1.2 Ручное развертывание

#### 1.2.1 Создание каталога

После установки вам нужно выбрать каталог для файлов конфигурации проекта, например можно создать папку с именем `xiaozhi-server`.

После создания каталога вам нужно создать внутри `xiaozhi-server` папки `data` и `models`, а внутри `models` — еще одну папку `SenseVoiceSmall`.

Итоговая структура каталогов выглядит так:

```
xiaozhi-server
  ├─ data
  ├─ models
     ├─ SenseVoiceSmall
```

#### 1.2.2 Загрузка модели распознавания речи

Для распознавания речи проект по умолчанию использует модель `SenseVoiceSmall` для преобразования речи в текст. Поскольку модель большая, ее нужно загрузить отдельно, после загрузки поместите файл `model.pt`
в каталог
`models/SenseVoiceSmall`. Выберите один из двух вариантов загрузки ниже.

- Вариант 1: загрузка с ModelScope (Ali ModelScope) [SenseVoiceSmall](https://modelscope.cn/models/iic/SenseVoiceSmall/resolve/master/model.pt)
- Вариант 2: загрузка с Baidu Netdisk [SenseVoiceSmall](https://pan.baidu.com/share/init?surl=QlgM58FHhYv1tFnUT_A8Sg&pwd=qvna) код извлечения:
  `qvna`


#### 1.2.3 Загрузка файлов конфигурации

Вам нужно загрузить два файла конфигурации: `docker-compose_all.yaml` и `config_from_api.yaml`. Эти файлы нужно скачать из репозитория проекта.

##### 1.2.3.1 Загрузка docker-compose_all.yaml

Откройте в браузере [эту ссылку](../../main/xiaozhi-server/docker-compose_all.yml).

В правой части страницы найдите кнопку с названием `RAW`, рядом с кнопкой `RAW` найдите значок загрузки, нажмите кнопку загрузки и скачайте файл `docker-compose_all.yml`. Сохраните файл в ваш
`xiaozhi-server`.

Или просто выполните `wget https://raw.githubusercontent.com/xinnan-tech/xiaozhi-esp32-server/refs/heads/main/main/xiaozhi-server/docker-compose_all.yml` для загрузки.

После загрузки возвращайтесь к этому руководству.

##### 1.2.3.2 Загрузка config_from_api.yaml

Откройте в браузере [эту ссылку](../../main/xiaozhi-server/config_from_api.yaml).

В правой части страницы найдите кнопку с названием `RAW`, рядом с кнопкой `RAW` найдите значок загрузки, нажмите кнопку загрузки и скачайте файл `config_from_api.yaml`. Сохраните файл в папку
`data` внутри `xiaozhi-server`, затем переименуйте файл `config_from_api.yaml` в `.config.yaml`.

Или просто выполните `wget https://raw.githubusercontent.com/xinnan-tech/xiaozhi-esp32-server/refs/heads/main/main/xiaozhi-server/config_from_api.yaml` для загрузки и сохранения.

После загрузки файлов конфигурации проверим, что весь `xiaozhi-server` выглядит так:

```
xiaozhi-server
  ├─ docker-compose_all.yml
  ├─ data
    ├─ .config.yaml
  ├─ models
     ├─ SenseVoiceSmall
       ├─ model.pt
```

Если структура каталогов у вас такая же — продолжайте дальше. Если нет, еще раз внимательно проверьте, не пропустили ли вы какой-то шаг.

## 2. Резервное копирование данных

Если вы раньше уже успешно запускали панель управления и на ней сохранены ваши ключи, сначала скопируйте важные данные с панели управления. Потому что в процессе обновления существующие данные могут быть перезаписаны.

## 3. Удаление образов и контейнеров старых версий
Далее откройте командную строку, с помощью инструмента `Терминал` или `Командная строка` перейдите в ваш `xiaozhi-server` и выполните следующие команды

```

```

## 4. Запуск программы
Выполните следующую команду для запуска контейнеров новой версии

```
docker compose -f docker-compose_all.yml up -d
```

После выполнения выполните следующую команду, чтобы просмотреть журнал.

```
docker logs -f xiaozhi-esp32-server-web
```

Когда вы увидите вывод журнала, это значит, что ваша `панель управления` запустилась успешно.

```
2025-xx-xx 22:11:12.445 [main] INFO  c.a.d.s.b.a.DruidDataSourceAutoConfigure - Init DruidDataSource
2025-xx-xx 21:28:53.873 [main] INFO  xiaozhi.AdminApplication - Started AdminApplication in 16.057 seconds (process running for 17.941)
http://localhost:8002/xiaozhi/doc.html
```

Обратите внимание: на данный момент работает только `панель управления`; если на порту 8000 `xiaozhi-esp32-server` выдает ошибку, пока не обращайте на это внимания.

Теперь вам нужно открыть в браузере `панель управления` по ссылке: http://127.0.0.1:8002 и зарегистрировать первого пользователя. Первый пользователь является суперадминистратором, все последующие пользователи — обычные. Обычные пользователи могут только привязывать устройства и настраивать агентов; суперадминистратор может управлять моделями, пользователями, параметрами конфигурации и т.д.

Далее нужно сделать три важных дела:

### Первое важное дело

Войдите в панель управления под учетной записью суперадминистратора, в верхнем меню найдите `Управление параметрами`, найдите первую запись в списке, код параметра — `server.secret`, скопируйте его в `Значение параметра`.

`server.secret` нужно пояснить: это `значение параметра` очень важно, его задача — позволить стороне `Server` подключаться к `manager-api`. `server.secret` — это ключ, который автоматически генерируется случайным образом при каждом развертывании модуля manager с нуля.

Скопировав `Значение параметра`, откройте файл `.config.yaml` в каталоге `data` внутри `xiaozhi-server`. Сейчас содержимое вашего файла конфигурации должно выглядеть так:

```
manager-api:
  url:  http://127.0.0.1:8002/xiaozhi
  secret: 你的server.secret值
```
1、Скопируйте `Значение параметра` `server.secret`, которое вы только что скопировали из `панели управления`, в поле `secret` файла `.config.yaml`.

2、Поскольку у вас развертывание через docker, измените `url` на следующий: `http://xiaozhi-esp32-server-web:8002/xiaozhi`

3、Поскольку у вас развертывание через docker, измените `url` на следующий: `http://xiaozhi-esp32-server-web:8002/xiaozhi`

4、Поскольку у вас развертывание через docker, измените `url` на следующий: `http://xiaozhi-esp32-server-web:8002/xiaozhi`

Результат должен выглядеть примерно так
```
manager-api:
  url: http://xiaozhi-esp32-server-web:8002/xiaozhi
  secret: 12345678-xxxx-xxxx-xxxx-123456789000
```

После сохранения продолжайте ко второму важному делу

### Второе важное дело

Войдите в панель управления под учетной записью суперадминистратора, в верхнем меню найдите `Настройка моделей`, затем нажмите `Большая языковая модель` в левой колонке, найдите первую запись `智谱AI (Zhipu AI)`, нажмите кнопку `Изменить`,
в открывшемся окне изменения введите ключ `智谱AI (Zhipu AI)`, который вы зарегистрировали, в поле `API-ключ`. Затем нажмите «Сохранить».

# Способ 2: Локальный исходный код, запуск всех модулей

## 1.Установка базы данных MySQL

Если MySQL уже установлен на этой машине, можно сразу создать в базе данных базу с именем `xiaozhi_esp32_server`.

```sql
CREATE DATABASE xiaozhi_esp32_server CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Если MySQL еще нет, вы можете установить mysql через docker

```
docker run --name xiaozhi-esp32-server-db -e MYSQL_ROOT_PASSWORD=123456 -p 3306:3306 -e MYSQL_DATABASE=xiaozhi_esp32_server -e MYSQL_INITDB_ARGS="--character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci" -e TZ=Asia/Shanghai -d mysql:latest
```

## 2.Установка redis

Если Redis еще нет, вы можете установить redis через docker

```
docker run --name xiaozhi-esp32-server-redis -d -p 6379:6379 redis
```

## 5.Установка окружения Python

Проект использует `conda` для управления зависимостями окружения. Если установить `conda` неудобно, нужно в зависимости от операционной системы установить `libopus` и `ffmpeg`.
Если вы решили использовать `conda`, то после установки выполните следующие команды.

Важное замечание! Пользователи Windows могут управлять окружением с помощью установки `Anaconda`. После установки `Anaconda` нажмите `Пуск`, введите ключевое слово `anaconda`,
найдите `Anaconda Prompt` и запустите его от имени администратора. Как показано на рисунке.

![conda_prompt](../images/conda_env_1.png)

После запуска, если вы видите слово (base) в начале командной строки, значит, вы успешно вошли в окружение `conda`. Тогда можно выполнить следующие команды.

![conda_env](../images/conda_env_2.png)

```
conda remove -n xiaozhi-esp32-server --all -y
conda create -n xiaozhi-esp32-server python=3.10 -y
conda activate xiaozhi-esp32-server

# 添加清华源通道
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge

conda install libopus -y
conda install ffmpeg -y

# 在 Linux 环境下进行部署时,如出现类似缺失 libiconv.so.2 动态库的报错 请通过以下命令进行安装
conda install libiconv -y
```

Обратите внимание: приведенные выше команды не выполняются успешно «одним махом» — нужно выполнять их шаг за шагом, и после каждого шага проверять выводимый журнал и убеждаться, что все прошло успешно.

## 8.Настройка файлов проекта

Войдите в панель управления под учетной записью суперадминистратора, в верхнем меню найдите `Управление параметрами`, найдите первую запись в списке, код параметра — `server.secret`, скопируйте его в `Значение параметра`.

`server.secret` нужно пояснить: это `значение параметра` очень важно, его задача — позволить стороне `Server` подключаться к `manager-api`. `server.secret` — это ключ, который автоматически генерируется случайным образом при каждом развертывании модуля manager с нуля.

Если в вашем каталоге `xiaozhi-server` нет папки `data`, вам нужно создать каталог `data`.
Если в папке `data` нет файла `.config.yaml`, можно скопировать файл `config_from_api.yaml` из каталога `xiaozhi-server` в `data` и переименовать его в `.config.yaml`

Скопировав `Значение параметра`, откройте файл `.config.yaml` в каталоге `data` внутри `xiaozhi-server`. Сейчас содержимое вашего файла конфигурации должно выглядеть так:

```
manager-api:
  url: http://127.0.0.1:8002/xiaozhi
  secret: 你的server.secret值
```

Скопируйте `Значение параметра` `server.secret`, которое вы только что скопировали из `панели управления`, в поле `secret` файла `.config.yaml`.

Результат должен выглядеть примерно так
```
manager-api:
  url: http://127.0.0.1:8002/xiaozhi
  secret: 12345678-xxxx-xxxx-xxxx-123456789000
```

## 9.Запуск проекта

```
# 确保在xiaozhi-server目录下执行
conda activate xiaozhi-esp32-server
python app.py
```

Если вы видите журнал, похожий на приведенный ниже, это признак успешного запуска сервиса проекта.

```
25-02-23 12:01:09[core.websocket_server] - INFO - Server is running at ws://xxx.xx.xx.xx:8000/xiaozhi/v1/
25-02-23 12:01:09[core.websocket_server] - INFO - =======上面的地址是websocket协议地址，请勿用浏览器访问=======
25-02-23 12:01:09[core.websocket_server] - INFO - 如想测试websocket请启动digital-human模块，打开浏览器交互测试
25-02-23 12:01:09[core.websocket_server] - INFO - =======================================================
```

Поскольку у вас развертывание всех модулей, у вас есть два важных интерфейса.

OTA-интерфейс:
```
http://你电脑局域网的ip:8002/xiaozhi/ota/
```

Интерфейс Websocket:
```
ws://你电脑局域网的ip:8000/xiaozhi/v1/
```

Обязательно запишите указанные выше два адреса интерфейсов в панель управления: они повлияют на выдачу адресов websocket и функцию автоматического обновления.

1、Войдите в панель управления под учетной записью суперадминистратора, в верхнем меню найдите `Управление параметрами`, найдите запись с кодом параметра `server.websocket` и введите ваш `Интерфейс Websocket`.

2、Войдите в панель управления под учетной записью суперадминистратора, в верхнем меню найдите `Управление параметрами`, найдите запись с кодом параметра `server.ota` и введите ваш `OTA-интерфейс`.


Далее вы можете приступить к настройке вашего устройства esp32: можно `скомпилировать прошивку esp32 самостоятельно`, а можно настроить использование `прошивки версии 1.6.1 и выше, скомпилированной Ся Гэ`. Выберите один из двух вариантов

1、 [Скомпилировать собственную прошивку esp32](firmware-build.md).

2、 [Настроить пользовательский сервер на основе готовой прошивки Ся Гэ](firmware-setting.md).
