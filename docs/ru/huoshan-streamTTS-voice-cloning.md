# Руководство по настройке двухпотокового синтеза речи и клонирования голоса Volcano в панели управления

Это руководство состоит из 4 этапов: подготовка, настройка, клонирование и использование. Оно описывает процесс настройки двухпотокового синтеза речи Volcano и клонирования голоса через панель управления.

## Этап 1. Подготовка
Суперадминистратор заранее активирует сервис Volcano Engine и получает App Id и Access Token. По умолчанию Volcano Engine предоставляет один голосовой ресурс. Этот голосовой ресурс нужно скопировать в наш проект.

Если вы хотите клонировать несколько голосов, необходимо приобрести и активировать несколько голосовых ресурсов. Достаточно скопировать в наш проект ID голоса (S_xxxxx) каждого голосового ресурса. Затем назначить их аккаунтам системы. Подробные шаги:

### 1. Активация сервиса Volcano Engine
Перейдите на https://console.volcengine.com/speech/app, создайте приложение в разделе управления приложениями, отметив «Большую модель синтеза речи» и «Большую модель копирования голоса».

### 2. Получение ID голосового ресурса
Перейдите на https://console.volcengine.com/speech/service/9999 и скопируйте три значения: App Id, Access Token и ID голоса (S_xxxxx). Как на рисунке:

![Получение голосового ресурса](../images/image-clone-integration-01.png)

## Этап 2. Настройка сервиса Volcano Engine

### 1. Заполнение конфигурации Volcano Engine

Войдите в панель управления под учётной записью суперадминистратора, нажмите вверху «Настройка моделей», затем в левой части страницы настройки моделей выберите «Синтез речи», найдите «Двухпотоковый синтез речи Volcano» через поиск, нажмите «Изменить». Введите `App Id` вашего Volcano Engine в поле «ID приложения», а `Access Token` — в поле «Токен доступа». Затем сохраните.

### 2. Назначение ID голосового ресурса аккаунтам системы

Войдите в панель управления под учётной записью суперадминистратора, нажмите вверху `Словарь параметров`, в выпадающем меню перейдите на страницу `Конфигурация системных функций`. На странице отметьте `Клонирование голоса` и нажмите «Сохранить конфигурацию». После этого в верхнем меню появится кнопка `Клонирование голоса`.

Войдите в панель управления под учётной записью суперадминистратора, нажмите вверху «Клонирование голоса» → «Голосовые ресурсы».

Нажмите кнопку добавления, в поле «Название платформы» выберите «Двухпотоковый синтез речи Volcano»;

В поле «ID голосового ресурса» введите ID голосового ресурса вашего Volcano Engine (S_xxxxx) и нажмите Enter;

В поле «Принадлежность аккаунту» выберите аккаунт системы, которому хотите его назначить (можно назначить себе). Затем нажмите «Сохранить».

## Этап 3. Клонирование

Если после входа, нажав вверху «Клонирование голоса» → «Клонирование голоса», вы видите сообщение «У вашей учётной записи пока нет голосовых ресурсов, обратитесь к администратору для назначения голосовых ресурсов» — значит, на этапе 2 вы ещё не назначили ID голосового ресурса этому аккаунту. Вернитесь на этап 2 и назначьте голосовой ресурс соответствующему аккаунту.

Если после входа, нажав вверху «Клонирование голоса» → «Клонирование голоса», вы видите соответствующий список голосов — продолжайте.

В списке вы увидите соответствующие голоса. Выберите один из голосовых ресурсов и нажмите кнопку «Загрузить аудио». После загрузки можно прослушать звук или вырезать какой-либо фрагмент. Подтвердив, нажмите кнопку «Загрузить аудио».
![Загрузка аудио](../images/image-clone-integration-02.png)

После загрузки аудио в списке вы увидите, что соответствующий голос перешёл в состояние «Ожидает копирования». Нажмите кнопку «Немедленно скопировать». Через 1–2 секунды вернётся результат.

Если копирование не удалось, наведите курсор на значок «Информация об ошибке» — будет показана причина неудачи.

Если копирование прошло успешно, в списке вы увидите, что соответствующий голос перешёл в состояние «Обучение успешно». В этот момент можно нажать кнопку изменения в колонке «Название голоса», чтобы переименовать голосовой ресурс и удобнее выбирать его в дальнейшем.

## Этап 4. Использование

Нажмите вверху «Управление агентами», выберите любого агента и нажмите кнопку «Настроить роль».

В синтезе речи (TTS) выберите «Двухпотоковый синтез речи Volcano». В списке найдите голосовой ресурс с названием, содержащим «Клонированный голос» (как на рисунке), выберите его и нажмите «Сохранить».
